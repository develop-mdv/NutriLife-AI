# Контекст приложения NutriLife AI

Этот документ предназначен для предоставления контекста другим LLM (ChatGPT, Claude, Gemini и др.) при работе над задачами по проекту NutriLife AI.

## 1. Обзор проекта
**NutriLife AI** — это интеллектуальное мобильное приложение-компаньон для здорового образа жизни. Оно помогает пользователям отслеживать питание, физическую активность и сон, предоставляя персонализированные рекомендации на базе искусственного интеллекта.

## 2. Технологический стек

### 📱 Мобильное приложение (`/mobile`)
Приложение разработано на **React Native** с использованием **Expo** (Managed Workflow).
*   **Язык**: TypeScript.
*   **Фреймворк**: React Native 0.81+, Expo SDK ~54.
*   **Навигация**: React Navigation v7 (Native Stack, Bottom Tabs).
*   **Управление состоянием**: React Context API + Hooks.
*   **UI и Дизайн**:
    *   Стилизация с использованием `StyleSheet` и констант.
    *   `expo-linear-gradient` для создания градиентных фонов и элементов.
    *   `react-native-svg` для иконок и графиков.
    *   Дизайн-код: Glassmorphism, премиальные градиенты, поддержка темной и светлой темы.
*   **Работа с устройством**:
    *   `expo-sensors` (акселерометр/шагомер for Pedometer).
    *   `expo-location` (геолокация для прогулок).
    *   `expo-image-picker` (камера для фото еды).
    *   `expo-haptics` (виброотклик).
*   **Сетевое взаимодействие**: Axios.

### 🖥️ Серверная часть (`/server`)
REST API сервер для обработки данных и взаимодействия с AI.
*   **Платформа**: Node.js.
*   **Фреймворк**: Express.js.
*   **Язык**: TypeScript.
*   **База данных**: MongoDB (с использованием Mongoose ODM).
*   **Аутентификация**: JWT (Access/Refresh tokens).
*   **AI Интеграция**: Google Generative AI SDK (модели Gemini) для анализа фото еды и чат-бота.

## 3. Структура проекта
Проект представляет собой монорепозиторий, содержащий клиентскую и серверную части.

*   `mobile/` — Исходный код мобильного клиента.
    *   `src/screens/` — Экраны (Auth, Dashboard, FoodLogger, Chat, Profile, Walks).
    *   `src/navigation/` — Конфигурация навигации.
    *   `src/components/` — Переиспользуемые UI компоненты (кнопки, карточки, инпуты).
    *   `src/context/` — Провайдеры контекста (User, Theme).
    *   `src/hooks/` — Кастомные хуки.
    *   `src/api/` — Взаимодействие с бэкендом.
    *   `src/constants/` — Цветовые схемы, шрифты, конфигурация.
*   `server/` — Исходный код бэкенда.
    *   Основные обработчики логики, модели данных и маршруты API.

## 4. Ключевой функционал

### 🏠 Dashboard (Главная)
*   **Кольца активности**: Визуализация потребленных калорий, макронутриентов (БЖУ).
*   **Трекинг**: Быстрое добавление воды и сна.
*   **Шагомер**: Отображение шагов в реальном времени.

### 📸 AI Food Logger (Дневник питания)
*   Анализ фотографий еды с помощью Google Gemini.
*   Автоматическое определение блюда, веса и КБЖУ.
*   Оценка "здоровости" блюда (Health Score).

### 💬 AI Coach (Чат)
*   Персональный ассистент, знающий контекст пользователя (цели, параметры).
*   Возможность корректировки планов питания и тренировок через чат.

### 🚶 Walks (Прогулки)
*   Генерация маршрутов для достижения цели по шагам (например, "мне нужно еще 3000 шагов").
*   Предложение маршрутов через парки и зеленые зоны.

### 👤 Profile (Профиль)
*   Статистика и графики прогресса.
*   Настройки целей и "умные" будильники.
*   Система достижений (ачивок).

## 5. Особенности разработки
*   **API URL**: При разработке на устройстве необходимо указывать локальный IP адрес компьютера в конфиге.
*   **Дизайн**: Приоритет на "Wow-эффект", использование размытия (Blur), качественной типографики и анимаций.
